# MusicBar icon

Created with the built-in image generation tool, then exported to the standard macOS ICNS sizes with `sips` and `iconutil`.

The artwork is original to this project. It represents a musical note and equalizer; it does not use Apple's logo.

## Generation prompt

Create one polished macOS app icon for MusicBar, a compact menu bar music player. Use case logo-brand. Square 1024x1024. A centered rounded-square tile occupies 84% of canvas. Genuine transparent outer background. Tile has a coral-red to raspberry-pink gradient. Center a single original white musical note subtly combined with three equalizer bars, simple bold silhouette readable at 32px. Subtle raised glossy material and delicate highlights, restrained modern macOS dimensional style, orthographic front view. No text, no Apple logo, no watermark, no mockup. Deliver finished icon only.

## Refinement prompt

Edit the supplied MusicBar icon. Keep the red-to-pink rounded-square tile and central white music-note plus equalizer mark unchanged. Clean up the transparent perimeter completely: remove EVERY stray red or pink pixel, floating fragment, speckle, noise and halo outside the rounded tile. Especially clear the fragments above and below the tile. Use a perfectly clean smooth alpha boundary. Center the complete icon in a square canvas with a consistent 8% fully transparent margin on every side, no clipping. No external drop shadow. Preserve the original icon design and high quality polished material. Output one production-ready app icon on genuinely transparent background.
